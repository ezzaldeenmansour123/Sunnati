# تنسيق حزمة المكتبة الموسعة — SUNNATI Package Format v1

> **الحالة:** مواصفة نافذة من المرحلة 7. لا توجد أي حزمة منشورة بعد —
> المكتبة الموسعة «قيد التجهيز». هذه المواصفة تصف كيف تُبنى حزمة
> **عندما** تتوفر بيانات موثقة، ولا تُنشئ بيانات وهمية.

## بنية الحزمة

```
<library_id>-<version>/
  manifest.json        # البيان (هذا التنسيق، الإصدار 1)
  <library_id>.db      # ملف SQLite (جداول مخطط SUNNATI)
  LICENSE.txt          # نص الترخيص حرفياً من المصدر
```

## `manifest.json`

| الحقل | مطلوب | الوصف |
|---|---|---|
| `format` | نعم | `"sunnati-package"` ثابت |
| `format_version` | نعم | `1` |
| `library_id` | نعم | `^[a-z0-9][a-z0-9_-]{0,63}$` |
| `name` | نعم | الاسم العربي للعرض |
| `version` | نعم | دلالي `x.y.z` |
| `source` | نعم | اسم المصدر — لا يكون فارغاً أبداً |
| `license` | نعم | معرّف الترخيص (مثل `ODbL-1.0`) — لا يكون فارغاً أبداً |
| `license_url` | لا | الرابط القانوني للترخيص |
| `files` | نعم | قائمة غير فارغة من `{path, sha256, size_bytes}` |
| `total_bytes` | نعم | مجموع `files[].size_bytes` |
| `created_at` | نعم | طابع ISO-8601 UTC |
| `min_app_version` | لا | مثل `1.0.0` |

## قواعد التحقق (يطبقها التطبيق قبل أي تثبيت)

1. **SHA-256:** كل ملف يُحسب تدفقياً (بأجزاء 1 MiB، لا يُحمَّل كاملاً
   في الذاكرة) ويُقارن ببيان الحزمة؛ أي اختلاف = رفض الحزمة وحذف
   ملفاتها، ولا تُثبَّت أبداً.
2. **الحجم:** `total_bytes` يجب أن يساوي مجموع الملفات؛ حزمة أكبر من
   2 GiB تُرفض (تُقسَّم أو تُعرض على المالك أولاً).
3. **المسارات:** نسبية فقط، بفاصل `/`، بلا `..` وبلا `/` بادئة وبلا
   حرف محرك أقراص وبلا `\` — الحزمة لا تكتب خارج مجلدها أبداً
   (حماية من اجتياز المسار).
4. **الامتدادات المسموحة:** `.db` و`.json` و`.txt` و`.md` فقط.
5. **النقل:** HTTPS فقط؛ رابط غير TLS يُرفض.
6. **الاستكمال:** ملف جزئي `<name>.part` يُحفظ عند الإيقاف/الفشل،
   والمحاولة التالية ترسل `Range: bytes=<received>-`. خادم يتجاهل
   `Range` يعيد الملف من الصفر (يُفرَّغ الجزئي ولا يُخلط).
7. **التحديث الجزئي:** يُقارن الإصدار دلالياً (`isUpdateAvailable`)؛
   لا تحديث بلا بيان جديد صالح.

## بناء حزمة (أداة سطح مكتب — لا تُبنى من داخل التطبيق)

```sh
python3 tools/build_package.py --db payload.db --library-id darqutni \
  --name "سنن الدارقطني" --version 1.0.0 \
  --source "verified-source-name" --license "ODbL-1.0" \
  --license-file LICENSE.txt --out packages/
```

الأداة ترفض البناء عند غياب ملف القاعدة أو نص الترخيص أو `--source`
أو `--license`، وتحسب SHA-256 من الملفات الحقيقية ثم تتحقق من الحزمة
قبل إعلان نجاحها.
